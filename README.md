## 使用方法

将 modified 文件中的内容 打包成 zip 并重命名为 errorpage （即 errorpage.zip ）  
替换 360 浏览器安装目下的同名文件即可 若替换时浏览器已在运行 则需要重启浏览器以使替换生效  

值得注意的是 浏览器更新后 errorpage.zip 会被覆盖 需要重新进行手动替换  
（实际观测到的行为是生成新的目录 即旧文件不变 更新的版本在新的子文件夹内）
